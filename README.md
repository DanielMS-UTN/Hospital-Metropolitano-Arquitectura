# Hospital Metropolitano SaludCloud - Arquitectura de Software

Proyecto del curso ISW-322 Introducción a la Arquitectura del Software
Universidad Técnica Nacional (UTN) - III Cuatrimestre 2026

## Caso de estudio
Modernización de la plataforma de gestión médica del Hospital Metropolitano SaludCloud, 
con una solución propuesta para Microsoft Azure: gestión de pacientes y expedientes, especialidades y médicos, reserva y cancelación de citas, notificaciones automáticas y consulta preliminar de costos.
